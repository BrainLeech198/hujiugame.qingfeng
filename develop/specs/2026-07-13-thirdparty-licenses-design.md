# 第三方素材版权声明方案

## 背景

项目使用了部分免费商用素材，原作者要求署名。需要在发行包中附上版权声明以满足许可协议的法律要求。

## 方案选型

- **方案 A（推荐）**：单文件 `THIRDPARTY_LICENSES.md`，放在发行包根目录，源码中维护在 `assets/` 下
- 格式：Markdown
- 条目排列：流水号顺序

## 文件规格

| 属性 | 值 |
|------|----|
| 文件名 | `THIRDPARTY_LICENSES.md` |
| 编码 | UTF-8 |
| 源码位置 | `assets/THIRDPARTY_LICENSES.md` |
| 发行包位置 | 游戏根目录 |

## 条目模板

每个素材条目包含以下字段：

```markdown
========================================
N. [素材名称]
========================================
文件:    相对路径
作者:    原作者名
来源:    原素材 URL
许可:    许可协议名称
修改:    是/否
说明:    修改内容描述（如有）

许可全文:
  [协议原文或指向原文链接]
---
```

## 文件结构

- 文件头部：项目名称、版权人、本文件用途说明
- 逐条：编号 → 素材名称 → 元数据字段 → 许可全文
- 条目之间用 `---` 分隔

## 后续维护

- 每新增第三方素材，在末尾追加新条目
- 修改素材（裁切/调色等）在"说明"字段记录
- 随版本更新同步检查许可协议变更
