# 第三方素材版权声明规范

> **文档定位**：定义第三方素材版权声明的文件布局、条目格式、维护流程，确保满足各许可协议的法律要求。
>
> **文档结构**：
> - 按 `目的 → 文件体系 → 资产路径约定 → 条目模板 → 新增流程 → 检查清单 → 维护规则 → 构建流水线` 顺序编排
> - 条目模板按许可类型分节（CC0 / CC BY / SIL OFL / 免费可商用 / AI 生成）
> - 每种模板包含：完整模板文本 + 字段说明 + 示例
>
> **更新规范**：
> 1. 【必须】更新 `develop/CHANGELOG.md` 记录本次变更
> 2. 【必须】新增许可类型时补充对应的条目模板和字段说明
> 3. 【必须】修改声明格式时同步更新 assets/ 和 docs/ 下的 `THIRDPARTY_LICENSES.*` 文件

## 目的

项目使用了部分免费商用素材，其许可协议要求署名或保留声明。本规范定义第三方素材版权声明的文件布局、条目格式、维护流程，确保满足各许可协议的法律要求。

## 资产路径约定

### 路径基准

所有路径相对于 `assets/` 目录（即项目根目录下的资源根目录），不使用前缀 `assets/`。

```
项目根目录/
  ├─ assets/
  │   ├─ asset/        ← 运行时资源根目录
  │   ├─ game/         ← 游戏作品目录
  │   └─ ...
  └─ ...
```

### 主题资源路径模式

主题相关资源统一位于 `asset/theme/{theme_name}/asset/resource/` 下：

| 类型 | 路径模式 |
|------|----------|
| 主题图片 | `asset/theme/{theme_name}/asset/resource/image/{用途}.{ext}` |
| 主题音频 | `asset/theme/{theme_name}/asset/resource/audio/{用途}.{ext}` |
| 主题字体 | `asset/theme/{theme_name}/asset/resource/font/{字体名}/` |
| 通用图片 | `asset/resource/image/{用途}.{ext}`（跨主题共享） |
| 通用音频 | `asset/resource/audio/{用途}.{ext}`（跨主题共享） |

### 路径填写示例

```
# 正确（去掉 assets/ 前缀）：
文件:    asset/theme/default_theme/asset/resource/image/menu.background.png

# 正确（通用资源）：
文件:    asset/resource/image/app_repair.png

# 错误（包含 assets/ 前缀）：
文件:    assets/asset/theme/default_theme/asset/resource/image/menu.background.png
```

## 条目模板与字段说明

### 模板

```markdown
## N. [素材名称]

- **文件：** `资源相对路径`
- **作者：** 原作者名或组织
- **来源：** URL 或出处描述
- **许可：** 许可协议名称（附链接）
- **修改：** 是/否
- **说明：** 修改内容描述（如有修改时必填）

[许可全文/署名要求/使用条款]
```

### 字段说明

| 字段 | 必填 | 说明 |
|------|------|------|
| 素材名称 | 是 | 中文描述，一目了然的素材用途 |
| 文件 | 是 | 按「路径基准」约定的相对路径，用反引号括起 |
| 作者 | 是 | 原作者名或组织名，原文保留 |
| 来源 | 是 | 下载页 URL（推荐）或具体出处描述 |
| 许可 | 是 | 协议全称 + 协议原文链接 |
| 修改 | 是 | `是` 或 `否`，即使仅调整尺寸/裁切也填 `是` |
| 说明 | 若修改 | 描述具体修改内容（调整尺寸、配色、组合叠加等） |

### 许可类型处理

不同协议的署名要求不同，统一格式如下：

**CC0 1.0（公有领域，无需署名）：**

```markdown
- **许可：** [CC0 1.0](http://creativecommons.org/publicdomain/zero/1.0/)（公有领域，无需署名）
```

无需许可全文段落，简短标注即可。

**CC BY 4.0（须署名）：**

```markdown
- **许可：** [CC BY 4.0](https://creativecommons.org/licenses/by/4.0/)

本作品使用了 {作者} 提供的 {类型}素材，按 CC BY 4.0 协议声明如下：

**署名：**
> {标准署名文本}

**使用条款：**
- 可用于商业项目，无需额外支付版权费用
- 必须署名作者并提供来源链接
- 可修改素材，修改后仍需署名
- 不得作为独立文件转售、再许可或分发
- 不得作为商标、服务标志或应用图标使用
- 不得用于色情、欺诈、非法或诽谤性内容
```

**SIL OFL 1.1（字体）：**

```markdown
- **许可：** [SIL Open Font License 1.1](https://openfontlicense.org)

本图像使用 {字体名} 字体渲染生成。字体本身受 SIL OFL 1.1 保护：

- 可免费用于个人和商业项目
- 可与其他软件捆绑分发
- 不得单独销售字体文件
- 衍生版本不得使用原字体名称
```

**免费可商用须署名（作者自定义条款）：**

```markdown
- **许可：** 免费可商用，须署名

{素材类型}由{作者名}提供，按作者要求声明如下：

**署名：**
> {作者指定的署名文本}

**使用条款：**
- 可用于商业项目，无需额外支付版权费用
- 不得以任何形式修改或声称拥有著作权与署名权（依作者要求）
- 不享有独家使用权
- 不得作为商品直接转售
- 使用时须遵守适用法律法规，不得用于违法违规事项
```

**AI 生成素材：**

```markdown
- **来源：** [豆包AI](https://www.doubao.com)
- **许可：** 视觉素材可商用（需二次设计后再使用）

本作品使用了 {AI平台} 生成的图像素材，按平台商用说明声明如下：

- 可用于海报、官网背景、社媒配图等视觉场景
- 建议进行二次设计后再使用（加入品牌色、版式、文案等原创元素）
- 不建议直接原样大图售卖或作为独家 IP 素材
- 用于商标/Logo/产品外观专利时需进一步差异化设计
```

## 文件结构

### assets/THIRDPARTY_LICENSES.md 总体布局

```
# 项目名称 — 第三方素材著作权声明

- 项目：{项目名}
- 版权所有：(c) {年份} {版权人}
- 项目主页：{项目 URL}

本文件列举了项目中使用的第三方素材及其许可信息。
如无特殊说明，项目自有代码和素材以根目录 `LICENSE`（{协议名}）为准。

---
## 1. {素材名称}
...
---
## 2. {素材名称}
...
---
...
---
## N. 原创素材（无需声明）

以下素材为项目自有创作，不涉及第三方著作权：
...
```

### 条目排列顺序

1. 按素材类型分组（图片 → 音频 → 字体 → AI 生成），组内按添加时间排列
2. 原创声明放在最后作为单独章节

### 条目分隔

条目之间使用 `---` 分隔（Markdown 水平线）。

## 新增第三方素材流程

1. **识别**：确认素材来源是否涉及第三方著作权
2. **记录**：收集作者、来源 URL、许可协议原文
3. **评估**：确认许可协议是否允许商业使用、是否要求署名
4. **填入**：按条目模板在 `assets/THIRDPARTY_LICENSES.md` 末尾追加
5. **更新官网**：同步更新 `docs/THIRDPARTY_LICENSES.html`
6. **提交**：在 CHANGELOG 中记录，随版本发布

### 新增条目检查清单

- [ ] 路径是否正确（无 `assets/` 前缀）？
- [ ] 作者名是否完整保留原始写法？
- [ ] 来源 URL 是否可访问？
- [ ] 许可协议链接是否有效？
- [ ] 修改字段是否如实填写？
- [ ] 署名文本是否与作者要求一致？
- [ ] 条目之间是否有 `---` 分隔？
- [ ] 是否同步更新了 `docs/THIRDPARTY_LICENSES.html`？

---

## 维护规则

1. **随增随记**：新增任何第三方素材后立即追加条目，不积压
2. **修改即记**：修改已有素材（裁切、调色、尺寸调整）更新「说明」字段
3. **版本检查**：库/框架升级时检查依赖中是否引入新第三方素材
4. **协议变更**：如原作者更新许可协议，评估变更对项目的影响并在条目中更新
5. **移除清理**：移除某素材时，在对应条目标注 `（已移除）` 并记录移除版本号，不直接删除条目（保留追溯能力）
